# Sentark Kullanıcı Rehberi — Kaynak İçerik

Bu repo, [docs.sentarktech.com](https://docs.sentarktech.com) adresinde yayınlanan
Sentark kullanıcı rehberinin kaynak içeriğidir (MDX). Site kodu ayrı bir repoda
tutulur; bu repo yalnızca dokümanları ve görselleri barındırır.

`main` dalına birleşen değişiklikler site derlemesini tetikler ve birkaç dakika
içinde yayınlanır (ayrıca haftalık zamanlanmış derleme de vardır).

## Düzenleme önermek

Küçük düzeltmeler için GitHub hesabı yeterlidir:

1. İlgili `.mdx` dosyasını açın ve kalem (Edit) simgesine tıklayın.
2. Değişikliği yapıp **Propose changes** ile pull request açın.

Daha kapsamlı katkılar (yeni sayfa, görsel, yapı değişikliği) için repoyu
klonlayıp PR açabilir ya da önce bir [issue](../../issues) açarak öneriyi
tartışabilirsiniz. Dosya ve söz dizimi kuralları için
[CONTRIBUTING.md](CONTRIBUTING.md) dosyasına bakın.
